# apps/web — Mirror Realm PWA

Vite + Phaser 3 + TypeScript. The full spec is [`docs/08-frontend-app.md`](../../docs/08-frontend-app.md).

```bash
pnpm install         # from repo root
pnpm gen             # generate src/domain/*.ts from packages/shared
pnpm --filter web dev
```

Open http://localhost:5173. For iPhone camera testing over LAN, see
[`docs/10-local-development.md#iphone`](../../docs/10-local-development.md).
